2.6.0 (2026-11-18)
• Патчноути тепер надсилаються лише при перетині цілої версії (2.x → 3.0). Малі оновлення більше не спамлять користувачів; усі нотатки збираються в один великий список до наступного мажорного релізу.
• У проді піднято Prometheus + Alertmanager: реальні percentiles доступні через /api/v1/query, алерти пишуться в логи бота.

2.5.1 (2026-11-18)
• Оптимізація: надсилання з кешу більше не чекає на два записи до Postgres — історія прослуховувань і жанри записуються у фоновому завданні після того, як аудіо вже відправлено.
• Графік динаміки жанрів будується за один прохід по подіях замість повторного сканування для кожної комбінації «жанр × інтервал».
• Деплой: gateway-образ тепер збирається через cargo-chef (кешування залежностей), а CI перевіряє збірку всіх трьох образів — бота, gateway і mock API для load-стенду.

2.5.0 (2026-11-18)
• Історія прослуховувань: /history [період] показує останні треки, а /dynamics [період] — графік динаміки жанрів за часом. Дані зберігаються в Postgres як метадані (без аудіо, обкладинок і текстів).
• Персональні дайджести: /digest daily|weekly активує щоденний або щотижневий огляд у приватні повідомлення, /digest quiet HH-HH задає тихі години (UTC), /digest off вимикає. Планувальник next_send_at лежить у Postgres, з захистом від подвійного надсилання кількома репліками.
• Повноцінний load-стенд: Rust mock Bot API, k6-сценарій, N реплік бота, Prometheus і Alertmanager. Реальні percentiles з /metrics, ніяких вигаданих чисел.
• Бот лишається на long polling; публічний вебхук не увімкнено, доки не буде піднято VM/домен.
